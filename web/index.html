FLOWER

The database with your application built in.

Build applications that stay in sync.

An order changes. Totals update. A dashboard refreshes. A delivery job becomes ready. Flower gives those moving parts a common foundation: transactional records, reactive computations, live queries, and durable workflows in one replicated engine.

Write your application logic in Rust. Define what changes and what depends on it. Flower tracks the connections and keeps the resulting state coherent.

Store the facts. Keep the consequences correct.

Define a customer’s balance, an order summary, or an inventory total as a computation over your data. Flower tracks what it reads and invalidates cached results when those dependencies change. Mutations publish source changes, indexes, and required derived values atomically; queries see one coherent snapshot.

Turn a query into a live view.

The same query that answers a request can power a live dashboard. Subscribe to its result and receive fresh snapshots as its dependencies change. Authorization is checked on delivery, and reconnecting clients get a fresh view.

Your types, all the way to the client.

Declare collections, queries, mutations, and errors in Rust. Run application logic in isolated WebAssembly guests. Share interface contracts with native clients and generate methods that carry your argument, result, and error types through the call.

Reach for SQL when it fits.

Use a typed, deployment-checked SQL plan for a query you know, or expose a scoped endpoint for request-time statements. Read-only SQL runs through ordinary module queries, with the same snapshot, access policies, and explicit resource budgets. Explain shows the access path before you read the rows.

Give background work a durable home.

Schedule a timer, enqueue a job, and let a native Rust worker handle the outside world. Durable queues, renewable leases, and fencing make ownership explicit. Persisted commands keep their identity through retries, and the client preserves uncertain outcomes so your application can recover deliberately.

A serious foundation beneath the convenience.

The engine validates tracked reads and writes before accepting a mutation. Raft replicates accepted changes and results; followers apply those consequences without rerunning your callbacks. Staged deployments, encrypted backups, and restore tooling support the application beyond its first successful request.
